# Pusterla Mercenari GmbH — Landing Page

Moderne, animierte Landing Page im Apple-Stil (Dark Mode + Glassmorphism / Frosted Glass) für das Schweizer Elektroinstallationsunternehmen **Pusterla Mercenari GmbH** aus Wolfhausen.

## 🔧 Technologien
- HTML5
- CSS3 (CSS Variablen, Glassmorphism, backdrop-filter, Responsive Grid)
- Vanilla JavaScript (Intersection Observer, Mobile-Menü, Smooth Scroll)
- Font Awesome (Icons)

## 📁 Projektstruktur

```
README.md
```

## 🎨 Design
- Dark Mode Hintergrund (`#0b0b0f`)
- Echtes Glassmorphism (`backdrop-filter: blur()`)
- Sanfte Neon-Glow-Effekte (Cyan / Violett) passend zu Strom & Elektrik
- Fade-in-Animationen beim Scrollen
- Hover-Effekte auf Karten und Buttons
- Vollständig responsive (Mobile-first optimiert)
